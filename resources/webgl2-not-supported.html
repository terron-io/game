Ошибка «WebGL2 not supported»

TERRON рисует карту через WebGL2 — современную графику в браузере. Эта ошибка значит, что ваш браузер не смог её включить. Обычно дело в старом драйвере видеокарты, выключенном аппаратном ускорении или отключённом WebGL. Ниже — как это починить (5 минут).

Проверка за 10 секунд. Откройте в ТОМ ЖЕ браузере https://webglreport.com/?v=2. Если и там «WebGL 2 is not supported» — дело не в игре, а в браузере/драйвере: дальше по инструкции. Если там всё работает, а игра ругается — напишите нам, это баг на нашей стороне.

Firefox

  1. Закройте Firefox ПОЛНОСТЬЮ (все окна, не просто вкладку) и откройте заново. WebGL у Firefox работает в отдельном GPU-процессе: если тот аварийно завершался несколько раз подряд, браузер перестаёт выдавать WebGL до полного перезапуска — F5 и новая вкладка тут не помогают. Признак ровно этот: «раньше играл, сегодня перестало, а другие сайты работают».
  2. Откройте новую вкладку, введите about:config, нажмите «Принять риск». В строке поиска по очереди найдите и выставьте:
    • webgl.disabled → false
    • webgl.force-enabled → true
    • webgl.enable-webgl2 → true
    • webgl.disable-fail-if-major-performance-caveat → true
  3. Меню ≡ → Настройки → «Основные» → «Производительность»: снимите «Использовать рекомендуемые», включите «Использовать аппаратное ускорение, если доступно».
  4. Перезапустите Firefox полностью и снова откройте игру.
  5. Если не помогло — откройте about:support, раздел «Графика»: строка «WebGL 2 Driver Renderer» и «Failure Log» подскажут причину (чаще всего — драйвер в чёрном списке, см. ниже).

Chrome / Edge / Яндекс

  1. Закройте браузер ПОЛНОСТЬЮ (все окна, а не вкладку) и откройте заново. Если GPU-процесс браузера аварийно завершался несколько раз подряд, браузер отключает ускорение до полного перезапуска — обновление вкладки тут не помогает.
  2. Настройки → «Система» → включите «Использовать аппаратное ускорение (при наличии)», перезапустите браузер.
  3. Откройте chrome://gpu — сверху в списке найдите «WebGL2». Если «Hardware accelerated» — WebGL2 в порядке; если «Software only» или «Disabled» — причина в драйвере/железе.
  4. Проверьте chrome://flags → поиск «WebGL»: ничего не должно стоять в «Disabled».

Windows: не душите видеокарту энергосбережением

Если карта слабая (встроенная Intel, старый ноут), Windows может гонять браузер в режиме экономии — а её и без того едва хватает. Из-за этого игра рвётся в бою («WebGL2 not supported» на середине матча). Разрешите браузеру полную производительность:

  1. Настройки графики. «Параметры» → «Система» → «Дисплей» → «Настройки графики» (в Windows 11: «Дисплей» → «Графика»). Выберите «Классическое приложение» → «Обзор» → укажите chrome.exe (обычно C:\Program Files\Google\Chrome\Application\chrome.exe) → «Параметры» → «Высокая производительность». Для Edge/Яндекс — тот же путь, только свой .exe.
  2. Режим питания. «Параметры» → «Система» → «Питание» (на ноутбуке — и от батареи, и от сети) → поставьте «Максимальная производительность», не «Экономия заряда». Во время игры ноутбук держите на зарядке.
  3. Перезапустите браузер (а лучше ПК) и снова откройте игру.

«Планирование графического процессора с аппаратным ускорением» можно оставить как есть — на старых Intel оно погоды не делает.

Если всё равно не работает

  • Обновите драйвер видеокарты — самый частый случай на Windows 7. Скачайте свежий с сайта NVIDIA / AMD / Intel и перезагрузите ПК.
  • Обновите браузер до последней версии (на Windows 7 последний Firefox — 115 ESR).
  • Очень старая видеокарта (до 2012 г.) может физически не уметь WebGL2 — попробуйте другой компьютер или ноутбук.
  • Попробуйте другой браузер (Firefox ⇄ Chrome) — иногда одному драйвер подходит, другому нет.

“WebGL2 not supported” error

TERRON renders its map with WebGL2 — modern in-browser graphics. This error means your browser couldn't turn it on. It's almost always an outdated graphics driver, hardware acceleration switched off, or WebGL disabled. Here's how to fix it (about 5 minutes).

A 10-second check. In the SAME browser open https://webglreport.com/?v=2. If it also says “WebGL 2 is not supported”, the problem is your browser/driver — follow the steps below. If that page works but the game still fails, tell us: that one is our bug.

Firefox

  1. Quit Firefox completely (every window, not just the tab) and start it again. Firefox runs WebGL in a separate GPU process: once that process has crashed a few times, the browser stops handing out WebGL until a full restart — reloading or opening a new tab won't help. The tell-tale sign is exactly “it worked yesterday, today it doesn't, and other sites are fine”.
  2. Open a new tab, type about:config, click “Accept the Risk”. Search for and set each of these:
    • webgl.disabled → false
    • webgl.force-enabled → true
    • webgl.enable-webgl2 → true
    • webgl.disable-fail-if-major-performance-caveat → true
  3. Menu ≡ → Settings → General → Performance: uncheck “Use recommended…”, enable “Use hardware acceleration when available”.
  4. Fully restart Firefox and open the game again.
  5. Still failing? Open about:support → “Graphics”. The “WebGL 2 Driver Renderer” and “Failure Log” lines show the reason (usually a blocklisted driver — see below).

Chrome / Edge

  1. Fully quit the browser (all windows, not just the tab) and reopen it. After several GPU-process crashes the browser disables acceleration until a full restart — reloading the tab does not help.
  2. Settings → “System” → enable “Use hardware acceleration when available”, then restart the browser.
  3. Open chrome://gpu and find “WebGL2” near the top. “Hardware accelerated” = good; “Software only” or “Disabled” points to a driver/hardware issue.
  4. Check chrome://flags → search “WebGL”: nothing should be set to “Disabled”.

Windows: don't starve the GPU with power saving

On a weak GPU (integrated Intel, old laptop) Windows may run the browser in power-saving mode — and it barely copes as it is. That's what makes the game break mid-match (“WebGL2 not supported” after you start playing). Let the browser run at full performance:

  1. Graphics settings. Settings → System → Display → “Graphics settings” (Windows 11: Display → Graphics). Pick “Desktop app” → “Browse” → select chrome.exe (usually C:\Program Files\Google\Chrome\Application\chrome.exe) → “Options” → “High performance”. For Edge use its own .exe.
  2. Power mode. Settings → System → Power (on a laptop, both on battery and plugged in) → set “Best performance”, not “Battery saver”. Keep the laptop plugged in while playing.
  3. Restart the browser (ideally the whole PC) and open the game again.

“Hardware-accelerated GPU scheduling” can be left as-is — it makes little difference on old Intel.

If it still doesn't work

  • Update your graphics driver — the most common fix, especially on Windows 7. Get the latest from NVIDIA / AMD / Intel and reboot.
  • Update your browser to the latest version (on Windows 7 the last Firefox is 115 ESR).
  • Very old GPUs (pre‑2012) may physically lack WebGL2 — try another computer.
  • Try a different browser (Firefox ⇄ Chrome) — a driver that fails in one sometimes works in the other.
